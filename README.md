# Crochet Pro

A calm website and pattern library for crochet makers.

## Develop

```bash
npm install
npm run dev
```

## Patterns

- Create patterns manually at `/library/new` (saved in the browser via localStorage).
- Each pattern can include an optional YouTube URL, which embeds on the detail page.
- Seed/spec patterns can still be added in `src/data/patterns.ts` as `seedPatterns`.
